# WeatherNow: City Weather Dashboard

**SkillMe Full Stack Engineer Virtual Internship — Week 1**

A static, responsive weather dashboard layout built with semantic HTML and CSS. Weather values shown are sample data; live search and API data are not part of Week 1.

## Features
- Accessible city search form with a visible-to-screen-readers label
- Current weather card with sample city, temperature, condition, wind speed and humidity
- Seven consistent forecast cards
- Responsive layout with horizontal forecast scrolling on small screens
- CSS variables, Flexbox, reusable classes and local image assets

## Project files
- `index.html` — page structure
- `style.css` — layout, styling and responsive rules
- `script.js` — prevents the static Week 1 form from reloading the page
- `assets/` — background and weather icons

## Run locally
Open `index.html` in a modern browser. An internet connection is needed only to load the optional Google Fonts; the local images and page layout work without them.

## Scope
This is a static Week 1 interface using sample data. JavaScript rendering and live weather from the Open-Meteo API are planned for later weeks.
